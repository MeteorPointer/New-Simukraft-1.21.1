# 核心之物 | 司辖之箧

诸物者，模组之要也，明其用乃营城之始。{spacing=8}

:item[simukraft:city_core]

邑之枢方砖：建邑之必备也，置之而右键即可立邑~{spacing=8}

:item[simukraft:build_box]

创世构匣：可雇匠师以建诸类之屋，亦可雇规师以划其域！{spacing=8}

:::right

:item[simukraft:residential_control_box]

宅屋之属司辖之箧：现于宅类之筑，藏其屋之记。

:item[simukraft:commercial_control_box]

市廛之属司辖之箧：现于商类之筑，于此可雇民役为肆人。{spacing=8}

# 司辖之箧 | 物流之网

:item[simukraft:industrial_control_box]

工肆之属司辖之箧：现于工类之筑，于此可雇工以司生产。{spacing=8}

:::right

:item[simukraft:logistics_server_box]

转运总枢：置于邑之仓廪，乃物流之纲也。{spacing=8}

:item[simukraft:logistics_client_box]

物流之从：置于邑中需物之处，以连器入物流之网。

# 余物 | 提示

此辅助之物，可使理邑更便。{spacing=8}

:item[simukraft:nsuk_farmland_box]

田作之椟：自动农产之核心，于此可雇农以司耕作。{spacing=8}

:item[simukraft:manifest]

清单：对创世构匣或控制箱潜行右键可读材列。对余块潜行右键可贴于地或墙，右键启之。


:::right

:item[simukraft:guide_book]

New:Sim-U-Kraft 指要：即君所览之卷，可随时翻阅以求助。

> 提示：击物之像，可观其合成之方（若已装JEI者）。

# 异食 | 异食

拟都所添异食数种，合民日常之用~

:item[simukraft:cheese_chunk]

酪块者，酪坊所产也，本可补腹二，亦可于「肯打鸡」造酪馅胡饼~

:::right

:item[simukraft:hamburger]

酪馅胡饼者，由饼+牛肉+酪块于「肯打鸡」造之，可补腹十二。

:item[simukraft:cheese_burger]

胡饼夹珍者，由饼+牛肉于「肯打鸡」造之，可补腹八。

# 异食 | 兴盛篇

:item[simukraft:french_fries]

油炙芋条者，由薯于「肯打鸡」造之，可补腹四。
