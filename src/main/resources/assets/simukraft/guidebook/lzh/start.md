# 始：建立新邑 | 创设篇

万事之始也，朝阳一缕。君启新程，然此次为一邑之长矣。{spacing=8}

:item[simukraft:city_core]

此乃邑之枢方砖也，由是块可立君之邑。

邑名不可与既有之邑相重，须二字以上，且不可有奇符。

:::right

若右上「世人口」有变，且有民入君之邑，则邑已立矣。

> 若未见君之民，请细查之。若实未现，恐立邑未成。

&nbsp;

> 邑之枢方砖既立，不可移也。如必欲移之，须由邑之枢方砖——>编辑邑——>毁邑而重立之，然资财与民亦皆失矣。

# 始：营造篇 | 营造篇

邑既立，君可谓能矣。继之，与吾辈共筑君之首屋。

## 择一筑而营之

先择一宅而建！须知：建筑须耗财、材、时三者。

除「单元一」外，余筑大抵需若干材，立邑之首日，宜建此屋。

## 匠师营造中……

君之首筑已起矣！其间，亦可往集材，备其后之造~

每置一方，匠师增经验一。经验既增，民役升级，劳作之效亦增。

# 立足：兴君之邑 | 兴盛篇

首民既得其家，是兴邑之时也，开拓者哉！

邑中若有空宅，则一日之午（六千刻），新民将入君之邑。

「单元一」之租薄，故第二日仍多耗启资。是建他筑之时矣！

:::right

## 租之道

每日清晨，民献其租，租之数为屋造价之三成。

故惟建廉屋如「单元一」者，虽免集材之劳，所获之租亦寡。

今宜备材，营较贵之筑（如五至七元者）！

# 立足：兴君之邑 | 兴盛篇

## 饱君之民

以前法兴邑既毕，或察一事：民皆饥矣！

诚然，民亦有腹度也。饥则劳作之效降，甚或殒之。

:::right

至简之法，乃手授食于民。上自附魔金苹，下至腐肉，皆可掷食于民以补其腹。

然民众既多，手掷甚劳。吾辈为长，自有上策。

至此——商筑之用乃显矣。

# 立足：兴君之邑 | 兴盛篇

## 建一商筑

商筑万象，有售食于民者，有售资于客者，亦有收物于客而授币于客者。

为饱民腹，可建售食于民之肆——如肉摊、肉铺、果肆、饼坊。

:::right

如自「肉摊」始，乃售鸡肉于民之简筑也。须供生鸡肉，雇肉摊之屠者，其将生肉炙之，售于来食之民！

# 扎根：趋养老之生！ | 扎根篇

## 卧而获材

倦于手集筑材与食物乎？须工筑也！

工筑既建，右键工肆之属司辖之箧即启其界。

雇工既毕，依所择之方而生产矣。其速与民役之级相关。

:::right

![](industry.png){width=256 height=256}

# 扎根：趋养老之生！ | 扎根篇

另有一处获筑材之佳所——筑商也。

筑商者，商类之筑也，雇肆人后可售诸筑材于客。

![](commercial.png){width=256 height=128}

:::right

兼之伐木之庐，亦可得诸种原木与剥皮原木。

然须知：诸商筑皆有库之上限，故不可无穷购也。

若库尽，候明日肆人补之；亦可多建以广其库。

# 扎根：趋养老之生！ | 扎根篇

## 物流之制

为省运物于工商诸筑之劳，君可立物流之制。

先建一仓！君可自设其仓，盈之以器，置「转运总枢」于其内。

:item[simukraft:logistics_server_box]

:::right

![](save.png){width=256 height=128}

若欲速始，亦可于创世构匣中择「他类」之仓，令民营之~

# 扎根：趋养老之生！ | 扎根篇

转运总枢既立，可雇仓之管事，并系一器。

继之，于需运物之近处置物流之从，亦于其内系器。

几乎诸工商之筑皆自带物流之从，可径于对应之处之从中系器。

## 模组中筑甚众，君可一一营之，享全集之乐！

:::right

物流虽善，然亦须费焉。

建仓之时，每器需二元。立物流之路时，逾二百五十六格者每运一组耗零点零二元；逾二百五十六之外，每超六十四格每组加零点零一元。

理而经之布邑，可省物流之费！
