# 始：建立新邑 | 创设篇

万事之始也，朝晖一缕，柔而温煦。君启新程，然此次为一邑之长矣。{spacing=8}

:item[simukraft:city_core]

此乃邑之枢方砖也，由是块可立君之邑。凡新邑初立，赐启资二十元。

邑名不可与既有之邑相重，须二字以上，且不可有奇符。

:::right

若右上「世人口」有变，且有民入君之邑，则邑已立矣。

> 若未见君之民，请细察之。若实未现，恐立邑未成也。

&nbsp;

> 邑之枢方砖既立，不可移也。如必欲移之，须由邑之枢方砖——>编辑邑——>毁邑而重立之，然资财与民亦皆失矣。

&nbsp;

> 欲随处理邑？造一随身邑枢，右键即启邑之菜单，何地皆可司之~

先择一宅而建！须知：建筑须耗财、材、时三者。

除「单元一」外，余筑大抵需若干之材。立邑之首日，宜建此屋。

# 立足：兴君之邑 | 兴盛篇

## 人口之道

邑中若有空宅，则一日之午（六千刻），新民将入君之邑。

成年之民亦相恋焉：独身之民，每日或有缘遇其心上之人。既成婚，夫妇同居一宅，燕尔新婚，其甜如蜜~

其家若有榻三张以上，已婚夫妇亦可育儿女——子每日长一岁，十八而冠，冠则可佣，与君共筑此邑~

:::right

## 邑之等第

邑自一等「拓荒者」始，可升至十二等「不夜之都」！

升等须人口、资财、材货皆备（初为原木圆石，后须铁金乃至钻石），于邑枢之菜单呈请，候其准焉。

等愈高，可占之区块与飞地愈广——十二等「不夜之都」，区块无上限，飞地至多十五！

# 立足：兴君之邑 | 兴盛篇

## 圈地拓土

邑之地非无偿也，须以财购之。

启邑枢之舆图：右键击一区块，于弹出之菜单择「认领区块」，可购一地；按鼠之中键（轮键）而曳之，可框选一域而批量认领（至多二百五十六块）。

与邑之领相连之区块，每块十元；不相连之飞地，每块五十元（四等始解）。

:::right

不需之地，亦可右键择「放弃区块」而退之。

# 立足：兴君之邑 | 兴盛篇

## 租之道

每日清晨，入宅之民献其租。租之数，与屋之造价相系——屋愈贵，租愈厚！

故惟建廉屋如「单元一」者，虽免集材之劳，所获之租亦寡。

今宜备材，营较贵之筑（如五至七元者）！

:::right

地若不足用？先升邑之等第，再往舆图圈新地——区块之上限，随等第而增也~

# 立足：兴君之邑 | 兴盛篇

## 饱君之民

以前法兴邑既毕，或察一事：民皆饥矣！

诚然，民亦有腹度也。饥则劳作之效降，甚或殒之。

:::right

至简之法，乃手授食于民。上自附魔金苹，下至腐肉（若欲令民食中毒者……），皆可掷食于民以补其腹。

然民众既多，手掷甚劳。吾辈为长，自有上策以解之。

至此——商筑之用乃显矣。

# 立足：兴君之邑 | 兴盛篇

## 建一商筑

商筑万象，有售食于民者，有售资于客者，亦有收物于客而授币于客者。

为饱民腹，可建售食于民之肆——如肉铺、果肆、饼坊。

:::right

如自「肉铺」始，乃售炙肉于民之简筑也。供以生牛之肉或生豕之肉，雇肉铺之屠者，其将肉炙之，售于来食之民！

> 欲与肆市易？右键肆人本身，即启市易之界。肆人依其市时作息，库竭则候其自补可也~

# 立足：兴君之邑 | 兴盛篇

## 民之疾患

民亦血肉之躯——气血过衰，或染时疫，皆辍其工而入医馆疗之。

于邑中建一医馆（内置病榻与医馆司辖之箧），聘医者则馆开。病者每百刻回血一，住院满一日则疾愈而出。

:::right

医馆所覆，乃其司辖之箧周遭一定区块之域。域内成家之民，方可有孕。

> 若无医馆，或榻皆满，则病者惟归家卧之，其疾不愈——欲其速复，医馆不可省也~

> 医者自病或休沐，则馆暂停收治。多建一馆，有备无患！

# 扎根：趋养老之生！ | 扎根篇

## 卧而获材

倦于手集筑材与食物乎？须工筑也！

工筑既建，右键工肆之属司辖之箧即启其界。

雇工既毕，依所择之方而生产矣。原料取于筑内之器，产物亦纳于器。大抵工之级愈高，方之产愈丰（每级加五厘）。

:::right

![](industry.png){width=256 height=148}

# 扎根：趋养老之生！ | 扎根篇

另有一处获筑材之佳所——筑商也。

筑商者，商类之筑也，雇肆人后可售诸筑材于客。

然须知：诸商筑皆有库之上限，故不可无穷购也。

若库尽，肆人将依各自之律自补之。亦可多建以广其库。

:::right

兼之伐木之庐，亦工筑之一也：伐木工伐其工域三十二格内之天生之木，耗树苗而复植之——常使伐木者行囊之树苗充盈，则所伐之原木自积于出器之中。

## 物流之制

为省运物于工商诸筑之劳，君可立物流之制。

先建一仓！君可自设其仓，盈之以器，置「转运总枢」于其内。

:item[simukraft:logistics_server_box]

:::right

![](save.png){width=256 height=128}

若欲速始，亦可于创世构匣「公共」之类中，择「小镇之仓」，令民营之~

# 扎根：趋养老之生！ | 扎根篇

以空手右键转运总枢，雇一仓之管事，并系诸器。

继之，于需运物之处置物流之从，亦于其内系器——几乎诸工商之筑皆自带物流之从。

于总枢建路既毕，管事将自调其运。管事若沐，物流亦停。

:::right

物流虽善，然转运亦须费焉。

每运一次，费二分；路逾二百五十六格者，逾分每六十四格加收一分。使厂近仓，则资财喜君！

# 扎根：趋养老之生！ | 扎根篇

## 凿矿？付之钻台！

后期之筑，耗材如流水。何不建一钻台，采掘亦自化之！

以地质锤右键击地（其耐八百，每探一次耗一），可探足下六十格内之虚矿。矿藏静卧地下，候钻以醒之~

于钻台置钻探司辖之箧，雇凿工则可凿矣。Y≥10用浅钻头，入更深之处则须深钻头；向下凿探须耗钻杆，愈深耗愈多。

:::right

所凿之矿，自入台内之桶。诸矿各依其律而出，富矿一日可出数批！

诸矿所藏，深浅各异。未定建台之所，宜先以地质锤探足下有何物。

> 锤言「无矿」者，勿灰心——矿区十之三，生而无矿。移二百五十六格外，再叩之可也~

# 生根：趋于养老之境！ | 生根篇

## 常见矿脉之布

论深浅：浅层（Y 零至四十八）有烟煤；中层（Y 十六至八十）有赤铁；近地表（Y 四十八至九十六）有褐煤、褐铁与孔雀石。斑铜、黄铁、青金藏于 Y 负三十二至十六；金在 Y 负五十六至负十六；钻石与红石惟最深之 Y 负六十四至负三十二有之；绿玉则反其道，惟 Y 九十六至一百九十二之高山出没~

:::right

矿脉亦择地形而生，记其诀可矣：「金藏于山根之底」——大雪之山麓，凿至最深；「绿玉宜于山巅勘之」——雪峰之肩可探；「红石何山皆可凿」——内陆丘壑，凿穿即得，乃深矿之上保。

铁观诸天：酷热之恶地与莽原出赤铁，湿沼丛林之畔出褐铁，高山深处藏黄铁。铜观诸地：沙漠平陆出孔雀石，温暖山地藏斑铜黄铜。煤观诸水：山麓出烟煤，水畔出褐煤~

# 发芽：圆君大都之梦！ | 发芽篇

## 钱庄与交易所

邑既富，则以钱生钱之时至矣！

建钱庄而聘柜者，则官员可存取钱币——所存之币入邑之资，取之则归君之囊。亦可汇资与他邑。

:::right

交易所者，邑之证券市也。每日辰初开市，戌初闭市，每时一价。聘经纪后，官员以邑资买卖股票，所持之股归于邑。

股价渐归于由邑之盛衰所算之「合理之价」——邑愈兴，价愈坚！

# 发芽：圆君大都之梦！ | 发芽篇

## 寰球市场

欲与他邑市易？建寰球市场，聘一贸者！

官员于此自定其价而挂牌：卖单之货存于市场之仓，售得之款归于邑；买单则邑资付之，货入于仓。

:::right

右键贸者，即可览一界诸邑之所挂，跨邑采买、出口创汇，皆随君意。

> 其价由挂牌之邑自定，货比三家，方不失利也~
