# Ключевые предметы | Блоки управления

Эти предметы — основа мода. Понимание их функций — первый шаг в строительстве города.{spacing=8}

:item[simukraft:city_core]

Городское ядро: необходимый предмет для создания города. Поставьте его и щёлкните ПКМ — город создан~{spacing=8}

:item[simukraft:build_box]

Строительный ящик: нанимайте архитекторов для возведения зданий разных типов или планировщиков для разметки территории!{spacing=8}

:::right

:item[simukraft:residential_control_box]

Жилой блок управления: появляется в жилых зданиях и хранит информацию о здании.

:item[simukraft:commercial_control_box]

Коммерческий блок управления: появляется в коммерческих зданиях. Здесь можно нанимать NPC-продавцов.{spacing=8}

# Блоки управления | Логистическая сеть

:item[simukraft:industrial_control_box]

Промышленный блок управления: появляется в промышленных зданиях. Здесь можно нанимать рабочих для производства.{spacing=8}

:::right

:item[simukraft:logistics_server_box]

Логистический сервер: размещается на городском складе и является ядром логистической сети.{spacing=8}

:item[simukraft:logistics_client_box]

Логистический клиент: размещается там, где нужны предметы, подключая контейнеры к логистической сети.

# Прочие предметы | Подсказки

Эти вспомогательные предметы делают управление городом ещё удобнее.{spacing=8}

:item[simukraft:nsuk_farmland_box]

Земельный ящик: ядро автоматизированного сельского хозяйства. Здесь нанимают фермеров для возделывания.{spacing=8}

:item[simukraft:manifest]

Манифест: присев + ПКМ по строительному ящику или контрольному ящику читает список материалов. Присев + ПКМ по другим блокам клеит его на пол или стену; ПКМ открывает список.


:::right

:item[simukraft:guide_book]

Руководство: эта самая книга, которую вы читаете. Открывайте в любой момент за справкой.

> Подсказка: щёлкните по иконке предмета, чтобы посмотреть рецепт крафта (если установлен JEI).

# Фирменные блюда | Фирменные блюда

Сим-У-Крафт добавляет несколько фирменных продуктов, отвечающих повседневной жизни горожан~

:item[simukraft:cheese_chunk]

Кусок сыра — продукт сырного завода. Сам по себе восстанавливает 2 ед. насыщения и используется в «Кэнь-Да-Цзи» для приготовления чизбургера~

:::right

:item[simukraft:hamburger]

Чизбургер: готовится из хлеба + говядины + куска сыра в «Кэнь-Да-Цзи». Восстанавливает 12 ед. насыщения.

:item[simukraft:cheese_burger]

Бургер с говядиной: готовится из хлеба + говядины в «Кэнь-Да-Цзи». Восстанавливает 8 ед. насыщения.

# Фирменные блюда | Глава о развитии

:item[simukraft:french_fries]

Картофель фри готовится из картофеля в «Кэнь-Да-Цзи». Восстанавливает 4 ед. насыщения.
