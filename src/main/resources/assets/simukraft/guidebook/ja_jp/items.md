# コアアイテム | コントロールボックス

これらのアイテムはmodの中核です。その機能を理解することが都市建設の第一歩となります。{spacing=1}

:item[simukraft:city_core]

都市コア：都市作成に必須のアイテム。設置後、右クリックで都市を作成できます~{spacing=1}

:item[simukraft:portable_city_core]

携帯都市コア：持ち歩ける遠隔マネージャー。右クリックすればどこからでも都市コアのメニューを開けます！{spacing=1}

:::right

:item[simukraft:residential_control_box]

住宅コントロールボックス：住宅建築物に出現し、住宅の情報を保存します。

:item[simukraft:commercial_control_box]

商業コントロールボックス：商業建築物に出現します。ここでNPC店員を雇用できます。{spacing=1}

# コントロールボックス | コントロールボックス

:item[simukraft:industrial_control_box]

工業コントロールボックス：工業建築物に出現します。ここで労働者を雇って生産できます。{spacing=8}

:item[simukraft:nsuk_farmland_box]

農地ボックス：自動化農業生産の中核。ここで農家を雇って耕作を始められます。{spacing=8}

:::right

:item[simukraft:medical_control_box] {spacing=1}

医療コントロールボックス：病院の心臓部。ベッドと雇われた医師があれば、市民の診察と入院はすべてここ任せ。

:item[simukraft:bank_control_box] {spacing=1}

銀行コントロールボックス：行員を雇えば、役人は硬貨の預け入れ・引き出しができ、他の都市への送金も可能です。

# 公共建築 | 物流ネットワーク

:item[simukraft:exchange_control_box]

取引所コントロールボックス：ブローカーを雇えば、役人は取引時間（8:00～20:00）に都市資金で株を売買できます。{spacing=8}

:item[simukraft:global_market_control_box]

グローバルマーケットコントロールボックス：貿易商を雇えば、役人が自由に価格を決めて出品し、ディメンション中の都市と取引できます。{spacing=8}

:::right

:item[simukraft:logistics_server_box]

物流サーバー：都市の倉庫に設置する、物流ネットワークの中核です。{spacing=8}

:item[simukraft:logistics_client_box]

物流クライアント：都市内でアイテムが必要な場所に設置し、コンテナを物流ネットワークに接続します。

# 新しい工業パーツ | 新アイテム

:item[simukraft:mineral_drilling_control_box] {spacing=1}

掘削コントロールボックス：掘削リグ建築の中に設置し、掘削作業員を雇えば採掘が自動化されます。

:item[simukraft:drill_rod_segment] {spacing=1}

掘削ロッド：坑道を下へ掘り進むときの消耗品。深く掘るほど多く消費します。{spacing=1}

:item[simukraft:geological_hammer] {spacing=4}

地質ハンマー：右クリックで足元60ブロック以内の仮想鉱脈を探査。その土地の価値を確かめましょう。

:::right

:item[simukraft:shallow_drill_bit] {spacing=4}

浅層ドリルビット：Y≥10の浅層掘削用。耐久値500。

:item[simukraft:deep_drill_bit] {spacing=4}

深層ドリルビット：深層岩盤層に突入するためのビット。耐久値900で長持ちします。

:item[simukraft:caution_tape] {spacing=4}

注意テープ：囲んだ区域を市民は自動的に迂回します。崖っぷちの守り神~

# 通貨 | ヒント

:item[simukraft:gold_coin]

金貨：額面1.00の通用通貨。市民の取引も物流料金もこれで精算されます~{spacing=1}

:::right

:item[simukraft:silver_coin]

銀貨：額面0.10。お釣りにどうぞ。{spacing=1}

:item[simukraft:copper_coin]

銅貨：額面0.01。最小額面の補助通貨です。{spacing=1}

# その他のアイテム | ヒント

これらの補助アイテムにより、都市管理がより便利になります。{spacing=8}

:item[simukraft:manifest]

マニフェスト：建築ボックスや制御箱をスニーク+右クリックで材料リストを取得。他のブロックへスニーク+右クリックで床や壁に貼れ、右クリックで開きます。

:::right

:item[simukraft:guide_book]

ガイドブック：今あなたが読んでいるこの本のこと。いつでも参照できます。

> ヒント：アイテムアイコンをクリックすると、クラフトレシピを確認できます（JEIインストール時）。

# 特色ある食べ物 | 特色ある食べ物

シムシティには、市民の日常に合わせた以下の特色ある食べ物が追加されています~

:item[simukraft:cheese_chunk]

チーズブロックはチーズ工場の生産物。それ自体で満腹度を2回復し、「ケンダジー」でチーズバーガーを作るのにも使えます~

:::right

:item[simukraft:hamburger]

チーズバーガーはパン+牛肉+チーズブロックを「ケンダジー」で作ります。満腹度を12回復します。

:item[simukraft:cheese_burger]

ビーフバーガーはパン+牛肉を「ケンダジー」で作ります。満腹度を8回復します。

# 特色ある食べ物 | 発展編

:item[simukraft:french_fries]

フライドポテトはジャガイモを「ケンダジー」で作ります。満腹度を4回復します。
